# @aperture/wasm

## Purpose

Compiles aperture's L402 macaroon primitives (HMAC-SHA256 signing, caveat
verification, identifier encoding) from Go to WebAssembly, providing a
single `aperture.wasm` binary that the TypeScript runtime loads for
cryptographically-correct macaroon operations.

## Key Types

- `jsMintMacaroon` — Mint a new macaroon with root key, payment hash, and caveats
- `jsVerifyMacaroon` — Verify macaroon HMAC-chain signature against root key
- `jsVerifyPreimage` — Check sha256(preimage) == paymentHash
- `jsEncodeIdentifier` / `jsDecodeIdentifier` — Version-0 L402 identifier codec
- `jsVerifyCaveats` — Verify caveats against built-in satisfiers (services + timeout)
- `jsAddFirstPartyCaveats` — Add caveats to an existing macaroon

## Module Structure

- `bridge.go` — Main WASM entry point; registers 7 functions on `globalThis.apertureWasm`
- `internal/l402/caveat.go` — Caveat encode/decode/verify (vendored from aperture v0.5.0)
- `internal/l402/satisfier.go` — Services, capabilities, timeout satisfiers
- `internal/l402/service.go` — Service type, service/capabilities/timeout caveat builders
- `testdata/gen_vectors.go` — Generates JSON cross-compatibility test vectors
- `Makefile` — `GOOS=js GOARCH=wasm go build` target

## Relationships

- **Depends on**: `gopkg.in/macaroon.v2` (HMAC-SHA256 macaroon library), `golang.org/x/crypto`
- **Depended on by**: [`@aperture/core`](../core/CLAUDE.md) (loads `aperture.wasm` via `src/macaroon/wasm.ts`)
- **External**: Go standard WASM target (`syscall/js`), CF Workers WASM module import

## Invariants

- The `internal/l402/` package is a vendored subset of `github.com/lightninglabs/aperture/l402` v0.5.0. It must stay in sync with upstream caveat semantics.
- The identifier codec uses big-endian: `uint16(version) || [32]byte(paymentHash) || [32]byte(tokenID)` = 66 bytes.
- The WASM binary must NOT import `lntypes`, `lnrpc`, or any lnd package — these don't compile to WASM. The identifier codec is inlined to avoid this.
- `main()` blocks forever with `select {}` to keep the WASM instance alive after registering exports.

## Build

```bash
make build   # Produces dist/aperture.wasm (~3MB, ~890KB gzip)
make clean   # Remove dist/
```

## Testing
